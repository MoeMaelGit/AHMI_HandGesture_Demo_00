# Demo Script

## Setup (before presenting)
1. Open Figma Slides presentation in Chrome — fullscreen (F11)
2. Open `index.html` in a second Chrome tab
3. Keep both tabs open; switch between them for the demo moment
4. Test gesture detection works from ~1–1.5m distance
5. Know the Space bar fallback if anything goes wrong

## During Presentation
At the "Prototype" slide section, switch to the demo tab.

**Narrator line:** "The robotaxi sees you on the street. Let's show how the hailing system works."

1. Stand ~1–1.5m from laptop, face camera
2. Raise open palm clearly → system detects → countdown starts
3. **Narrator:** "The system checks your intent — is this intentional?"
4. Show thumbs-up → 2s confirmation → animation plays
5. **Narrator:** "Confirmed. The taxi finds your pickup point and guides you there."
6. Animation completes → presentation auto-advances to next slide
7. If professor wants to try: hand them the laptop or let them stand in front

## Fallback
If gesture fails: press Space → animation plays → presentation advances.
Never mention the fallback unless asked.

## Timing
Full demo sequence: ~20–30 seconds
